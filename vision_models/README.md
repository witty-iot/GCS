# vision_models

Datasets and training work for the camera/vision-driven drone actions (not
the flight-control codebase — that's `swarm_system/`). Each action gets its
own subfolder: dataset, notes on source/license, and training work once it
starts.

Current:
- `window_cleaning/` — dust/dirt/stain detection on glass, for the
  `window_clean` action (lidar area mapping + CV dust detection + pressure
  decision). Dataset sourced, model training not started yet.
